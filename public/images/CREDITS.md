# Hero artwork

`hero-bedroom.webp` is a resized, WebP-encoded copy of `BedroomNight.png` from **Visual Novel Backgrounds** by **Kyuririn (Kyu)**.

- Artist and download: https://kyuririn.itch.io/visual-novel-backgrounds
- Source pack: `Backgrounds.zip`, `Backgrounds/Backgrounds/BedroomNight.png`
- Artist's published usage terms: “Free for personal and commercial use”; “Credit appreciated but not required.”
- Only resizing and WebP compression were applied to the file. The website applies a dark CSS fade for text readability.
- This is third-party hand-drawn artwork, not artwork created by the site owner or by this coding assistant.

The old hero referenced `https://assets.codepen.io/3364143/7btrrd.mp4`, which returned HTTP 404 when checked. This local still avoids that broken dependency and does not autoplay video.
